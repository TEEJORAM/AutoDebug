# Finalized fake-only foundation: unreleased

**Not a public release.** Package version: 0.1.0. Evidence schema: 0.2-draft.
Publication, license assignment, native debugger access and external transfer
remain blocked pending their respective authorizations.

## Finalization scope

The 63-file implementation is preserved in local commit
`736cc154dda574a54bfc4f42ebf16d6980d71ac1`. Finalization freezes that behavior
and updates public documentation only. The verified baseline is 468 tests.
No source, test, CI or dependency change is part of this finalization.

A focused current-file content check found no employee addresses, internal
URLs, personal workstation paths, genuine credentials or private operational
snapshots. Public vendor links and synthetic test markers are retained;
legitimate provenance and ownership records are not removed. This is not a
new security audit, history clearance or legal approval.

Publication requires only the four decisions in the
[approval request](ossa-legal-approval-request.md). Follow the
[publication steps](installation.md#publication-after-permission) afterward;
do not publish existing private history by default.

## Fixed

Nested structured variable secrets no longer survive stringification. Active
ownership survives unregister/re-register. Empty/partial/foreign breakpoint
binding sets cannot arm reproduction. Nonfinite/duplicate/tampered approvals
fail closed; monotonic expiry prevents wall-clock rollback extending approval.
Incomplete investigations can produce honest artifacts without being relabeled
successful. Backend failures cannot silently reopen a case or accept late data.
Cancellation is not blocked by value rendering, ownership is retained through
detach, and an in-flight cancelled target is quarantined before ownership
release. Late launches cannot leave a registered/authorized orphan.

The prior publication-hardening and strict-review repairs are retained,
including cross-case binding, file/link containment, scopes, exclusive evidence
IDs, lifecycle serialization, failed-arm rollback and report citation checks.

## Compatibility and migration

New API-script plans require actual content, matching digest and explicit review
metadata; digest-only plans are deliberately rejected. Launch/attach arguments
must match the reviewed plan. Conditional breakpoints remain denied pending a
separate evaluation policy. `0.1-draft` structural plan input is accepted subject
to these current safety rules; newly emitted artifacts use `0.2-draft`.
Existing case folders cannot be reopened as a new trusted investigation.
No historical evidence is automatically migrated or deleted.

Secure Windows evidence persistence remains unavailable. Native adapter proof,
OS-trusted approval and cooperative native cancellation require approved
external integrations. A noncooperative abandoned call can outlive the facade
wait; its target remains quarantined, not falsely reported stopped.
