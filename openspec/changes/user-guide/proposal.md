# User guide on GitHub Pages

Requested by the developer on 2026-10-24: the sample project is not enough to
use AutoDebug. They need one place, on GitHub Pages, with steps for Windows,
macOS and Linux and for VS Code, Cursor, CLion, Visual Studio and Xcode.

## Scope

- A static site the repository can publish with GitHub Actions.
- The same install, check and connect commands on the site and in
  `autodebug guide`.
- Honest per-IDE status: which clients `config` can write today, and that
  real debugger control stays disabled.

## Out of scope

Native debugger clients, the T05 security gate, new dependencies, invented
IDE config paths, and any claim that an IDE/OS cell is certified.
