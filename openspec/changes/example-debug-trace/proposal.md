# Local trace of the geometry sample

The developer expects an agent to debug `AutoDebugExample`: stop on the area
line, record the values, and write a markdown summary.

## Scope

- One MCP tool, `autodebug_debug_example`, that traces `geometry.py` in the
  AutoDebug process and writes `investigation.md`.
- The report states that no IDE breakpoint was set and Debug was not started.

## Out of scope

Controlling VS Code, Cursor, CLion, Visual Studio, or Xcode. The T05 gate
stays open.
