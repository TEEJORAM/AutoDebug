Use AutoDebug

Install once, then connect VS Code or Cursor on Windows, macOS or Linux. The same steps are in the repository at site/index.html.

Real debugger control is disabled until the T05 security gate is approved. Today AutoDebug runs a synthetic demo debugger. It does not attach to the debugger in VS Code, Cursor, CLion, Visual Studio or Xcode. autodebug config does not write CLion, Visual Studio or Xcode files.

Windows

PowerShell. Python 3.11 or newer (py) and Git.

1. Install

git clone https://github.com/TEEJORAM/AutoDebug.git
cd AutoDebug
py -m pip install -e .
py -m autodebug doctor

2. Connect an AI client

Replace the folder with the project you open in the editor. This writes that project's MCP config and keeps other servers.

py -m autodebug config vscode --demo --write D:\Projects\MyApp
py -m autodebug config cursor --demo --write D:\Projects\MyApp
py -m autodebug config claude-desktop --demo --write
py -m autodebug config claude-code --demo

Evidence from each server start goes to %LOCALAPPDATA%\autodebug, in a new run-… folder.

macOS

Terminal. Python 3.11 or newer and Git.

1. Install

git clone https://github.com/TEEJORAM/AutoDebug.git
cd AutoDebug
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
autodebug doctor

Run source .venv/bin/activate again in each new terminal.

2. Connect an AI client

autodebug config vscode --demo --write ~/Projects/MyApp
autodebug config cursor --demo --write ~/Projects/MyApp
autodebug config claude-desktop --demo --write
autodebug config claude-code --demo

Evidence goes to ~/Library/Application Support/autodebug.

Linux

Terminal. Python 3.11 or newer and Git.

1. Install

git clone https://github.com/TEEJORAM/AutoDebug.git
cd AutoDebug
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
autodebug doctor

2. Connect an AI client

autodebug config vscode --demo --write ~/Projects/MyApp
autodebug config cursor --demo --write ~/Projects/MyApp
autodebug config claude-code --demo

Claude Desktop has no known configuration path on Linux; use VS Code, Cursor or Claude Code. Evidence goes to ~/.local/state/autodebug (or $XDG_STATE_HOME/autodebug).

After config

VS Code

  1. Open the project folder you passed to --write.
  2. Command Palette → MCP: List Servers → autodebug → Start Server.
  3. Open Copilot Chat in Agent mode.

Cursor

--write creates .cursor/mcp.json in the project. Open Cursor Settings and enable autodebug under MCP, then use Agent chat.

Claude Desktop and Claude Code

Quit and restart Claude Desktop after --write. For Claude Code, run the claude mcp add command that config claude-code prints, in the project folder.

Ask this

Use the autodebug tools to investigate case AUTODEBUG-DEMO: show its status, the stack, and the variables local_var and password.

You should see a synthetic stack, local_var = 42 and password = ***REDACTED***. Case AUTODEBUG-DEMO is the built-in demo, not your application. The demo approval lasts 30 minutes; restart the MCP server after that.

Five IDEs

IDEWhere it runsWhat you can do now
VS Code Windows, macOS, Linux AI client via config vscode. Its own debugger is not driven by AutoDebug.
Cursor Windows, macOS, Linux AI client via config cursor. Its debugger is not driven by AutoDebug.
CLion Windows, macOS, Linux Open examples/AutoDebugDemo/cpp and debug it yourself. No verified JetBrains MCP path is written.
Visual Studio Windows File → Open → CMake… on examples/AutoDebugDemo/cpp/CMakeLists.txt. Not an AutoDebug client.
Xcode macOS Build the C++ sample with CMake if you want. mcpbridge is not wired up, and AutoDebug does not control Xcode.

examples/AutoDebugDemo is a small Python and C++ program with one deliberate area bug (geometry.py line 15). Debugging it in an IDE teaches the bug. It does not make AutoDebug control that debugger. On macOS and Linux, autodebug doctor lists which of the five adapters target that OS; all of them stay mock-only.

If something fails

What you seeWhat to do
No autodebug toolsRe-run config … --write from the AutoDebug folder, then restart the MCP server.
is not plain JSONThe existing file has comments. Run config without --write and paste the entry yourself.
serve sits stillIt is waiting for a client on stdin. That is expected. Ctrl+C to quit.
NOT_APPROVEDThe server was started without --demo. Reconfigure with --demo.
APPROVAL_EXPIREDThe 30-minute demo approval ended. Restart the server.
Evidence path errorPick a folder outside the AutoDebug checkout.
