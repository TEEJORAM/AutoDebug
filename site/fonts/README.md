# Fonts

`lemon-milk-*.woff2`: LEMON MILK by MARSNEV (https://www.marsnev.com), converted
from the .otf files and limited to Latin characters. The whole site uses it.
The font has capitals only, so passages use small capitals for lowercase letters
(`font-variant-caps: small-caps`) and headings stay full capitals.
MARSNEV's terms: free for personal, educational, non-profit or charitable use;
commercial use asks for a donation.
